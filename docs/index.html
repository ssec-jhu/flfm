Fourier Light-Field Microscopy

Reconstructing 3D images from a single snapshot.

About the Project

This project provides the tools to process data from a Fourier Light-Field Microscope (FLFM). Microscopes are powerful tools for looking at the very small, but they usually only capture a flat, 2D image. FLFM is a special technique that allows us to capture a 3D image in a single snapshot. This is incredibly useful for observing fast-moving biological processes.

However, the raw data from an FLFM isn't a picture you can look at directly. It's a complex pattern of light that needs to be computationally reconstructed to form a clear 3D image. This is where our software comes in.

How it Works

Our software uses a process called "deconvolution" to reconstruct the 3D image. Think of it like trying to un-blur a blurry photo, but in 3D. We use a mathematical model of the microscope's optics (the "Point Spread Function" or PSF) to reverse the image formation process.

The core of our software is written in Python and uses the popular machine learning libraries PyTorch and JAX to perform the heavy computations. This allows us to take advantage of powerful GPUs for speedy processing.
